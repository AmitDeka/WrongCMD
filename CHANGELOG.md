# Change Log

All notable changes to the "WrongCMD" extension will be documented in this file.

## [1.2.28.22] - 2026-02-28

### Added

- **Initial Release!** 🎉
- **Built-in Meme Sounds:** Added 4 default audio options (_Fahhh_, _Abe Sale_, _Baigan_, and _Anime Ahh_) to play when terminal commands fail.
- **Custom Audio Support:** Users can now specify an absolute path to play their own local `.wav` files.
- **Smart Terminal Detection:** Implemented VS Code's native Shell Integration API for highly reliable, cross-platform error detection without performance drops.
- **Customizable Error Keywords:** Added a configuration setting (`wrongcmd.errorKeywords`) allowing users to define exactly which terminal phrases trigger the audio, making it fully compatible with Bash, Zsh, PowerShell, and CMD.
